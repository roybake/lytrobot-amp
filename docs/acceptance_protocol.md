# LYT 双足机器人考核与评测规程

## 判定原则

仿真报告只用于训练前后的预验收。最终“满足指标”必须由课题 1 集成后的物理样机
完成同一套测试，并保留原始传感器、电功率和视频数据。部署策略必须是
`sensor_training/train_multimotion.py` 生成的严格 IMU + 肌腱长度策略，不能使用仿真
真值、参考相位、动作标签或地形标签。

## 硬指标

| 指标 | 合格线 | 仿真预验收 | 物理样机终验 |
|---|---:|---|---|
| 平地速度 | ≥5 km/h（1.3889 m/s） | 根节点世界坐标位移/时间 | 标定距离/光电门或动捕时间 |
| 当前训练参考速度 | 0.8623 m/s（3.10 km/h，CMU 69_01 原始重定向节奏） | 策略 rollout 均速 | 稳态测试段均速 |
| 平地比能耗 | ≤0.8 J/kg/m | 执行器绝对机械功积分 | 直流母线电功率积分 |
| 不平路 | 最大高度差 0.05 m | 实际高度场极差 | 测量最高点与最低点 |
| 上/下坡 | 最大坡度 ±6° | 地形几何实测角度 | 倾角仪实测角度 |
| 上/下楼梯 | 级高 0.13–0.20 m、踏面 0.22–0.32 m | 四个边界组合 | 实物尺寸复测 |
| 自适应切换 | 六场景连续完成 | 串行路线无人工切换 | 样机连续路线无人工切换 |

## 速度与能耗计算

平地测试应剔除起步和制动区，只统计稳定行走区间。速度为：

```text
v = forward_distance / elapsed_time
```

样机比能耗按题目给定的 `J/kg/m` 口径计算：

```text
energy = integral(abs(bus_voltage * bus_current), time)
specific_CoT = energy / (robot_mass * forward_distance)
```

质量必须包含电池、计算机、线束和测试时携带的全部载荷。电压、电流、时间戳和位移
必须来自同一测试区间；距离为零、跌倒或数据非有限值一律判失败。仿真使用更保守的
执行器绝对机械功 `sum(abs(force * velocity))` 积分。

## 六场景连续路线

路线至少依次包含：水平硬平地、5 cm 不平路、6°上坡、6°下坡、上楼梯、下楼梯。
场景交界处不允许重置策略、人工选择动作或输入地形标签。楼梯分别测试以下边界：

1. 0.13 m 级高、0.22 m 踏面；
2. 0.13 m 级高、0.32 m 踏面；
3. 0.20 m 级高、0.22 m 踏面；
4. 0.20 m 级高、0.32 m 踏面。

每个组合必须至少完整通过一次。发生跌倒、触发安全终止、离开路线、未访问任一场景
或未走完整条路线均判失败。

## 仿真预验收命令

```bash
uv run python scripts/evaluate_acceptance.py \
  --checkpoint logs/multimotion/stage2/<run>/model_final.pt \
  --device cuda
```

脚本默认评测平地速度/能耗和四种楼梯边界下的六场景串行路线。只有全部硬条件同时
满足才返回退出码 0，并在 checkpoint 目录生成 `acceptance_report.json`。

## 留档

终验至少保存：机器人总质量、地形实测尺寸、策略 checkpoint 哈希、控制频率、原始
电压/电流/位移 CSV、每次试验的起止时间、未剪辑全程视频、逐项结果和失败原因。
